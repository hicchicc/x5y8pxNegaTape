# x5y8pxNegaTape「ネガテープ」

(　現在作業中！　ここにサムネイル画像　)

## NegaTape is a negative space pixel font under SIL OFL 1.1
- テキスト入力だけで帯の中に文字が白抜きになる、ネガティブスペース・ピクセルフォントです。
- デジタル感のあるステータスバーや注意喚起の強調表示として便利です。
- 極小解像度ゲームでは主要フォントとして、通常解像度ゲームでは極小UIとして。
- 実験的な仕様もあるフォントなので、厳密な挙動を期待し過ぎずお楽しみ下さい。

## 収録グリフ
- 約450グリフを収録。基礎ラテン文字、ひらがな、カタカナ、記号類、全角形など。
- 英数字とカタカナをメインで使用することを想定しています。

## 垂直メトリクス設計
- 文字サイズ8px(6pt)の倍数でドットバイドット表示ができる想定になっています。
- 帯の高さは7px相当の極小サイズなので、8pxグリッドの画面で密着せず改行できます。
- ディセンダーは帯の下端に接しています。バケツツールなどでの塗り潰し時にご注意下さい。

## 水平メトリクス設計
- 多くのグリフ5pxの文字送り幅と4pxの文字を持ちますが、等幅フォントではありません。
- 左サイドベアリングは大半が0で、テキストの始点に密接します。
- 右サイドベアリングは負の値を持ちます。直後の文字と重ね合わせることで帯が繋がる設計です。
  - 半透明テキストを表示すると重複部分が濃くなるので、不透明なテキストで運用するのがおすすめです。
  - 重ね合わせではなく距離0の隣接になる部分もあり、わずかに白抜きが漏れて表示されることがあります。
  - このような場合、ごくわずかに文字間隔を狭めるか文字を太らせるとよいでしょう。 

## スペース系グリフについて
- 多くのスペース系グリフは空白ではなく「黒塗りの帯」が表示されます。
- U+0020 Space でも黒塗りの帯が表示され、単語間を連結します。
  - Opentype ccmpフィーチャーによってU+0020 Spaceの代替としてU+2002 En Spaceが表示されます。
  - U+0020 Spaceを直接黒塗りのグリフにするとWindows環境で不具合が生じるため、この方法を取っています。
  - Opentype機能のない環境では U+0020 Space は黒い帯ではなく空白となります。
- En Quad, Em Quad, Thin Space, Hair space は黒塗りでなく、純粋な余白取り用に使えます。
- 垂直線(|)、全角垂直線(｜)も帯を区切ることのできるように設計しています。
  - " TEXT1 | TEXT2 | TEXT3 " あるいは "||| TEXT |||" といった感じで使ってみて下さい。

## 全角形グリフについて
- 全角形グリフ（U+FF01 から U+FF60）は、文字送り幅5px相当の等幅となっています。
  - ほとんどのグリフの形状は基礎ラテンと同じです。
  - テキストを全角英数字で入力するか、fwidフィーチャーをオンにすることで等幅フォントのように見せることもできます。
